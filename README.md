# XC3 HD Texturen

KI-Upscaling fuer Xenoblade Chronicles 3 in Eden: Charaktere, Waffen, Monster, Objekte und Kartentexturen.
Nur fuer den eigenen Gebrauch mit einem Dump der eigenen Spielkopie.

- `src/XC3HD.ps1` – Programm (WPF-Oberflaeche + Engine)
- `maptex/` – `xc3_maptex`, Export/Import von Kartentexturen (.wismhd/.wismda) auf Basis von xc3_lib
- `launcher/` – portabler EXE-Starter
