# Änderungen / Changelog

Der Abschnitt der jeweiligen Version wird beim Release als Patchnotes übernommen und im Updater angezeigt
(in den Einstellungen und in der Update-Frage). Deutsch für die deutsche Oberfläche, English für alle anderen Sprachen.

## 1.9.0

### Deutsch
- Detailansicht pro Spiel: Ein Klick auf eine Kachel öffnet rechts eine Leiste mit Cover, zuletzt gespielt, Spielzeit, installiertem Update, DLC, Mods, Title-ID und Datei. Von dort geht es direkt zu Mods, Updates & DLC und Spieldaten dieses Spiels.
- Spielzeit: Die von Eden gezählte Spielzeit steht in der Detailansicht, im Tooltip der Kachel und unter „Weiterspielen“.
- Patchnotes des Updaters: Die Einstellungen zeigen, was eine neue Version bringt bzw. was die installierte gebracht hat. Auch die Update-Frage beim Start nennt die Änderungen.
- Themeauswahl und Meldungsfenster haben jetzt dieselbe eigene Titelleiste wie das Hauptfenster.

### English
- Game details: clicking a tile opens a side panel with cover, last played, play time, installed update, DLC, mods, title ID and file. From there you can jump straight to this game's mods, updates & DLC and save data.
- Play time: the play time counted by Eden is shown in the details, in the tile tooltip and under “Continue playing”.
- Updater patch notes: the settings show what a new version brings, or what the installed one brought. The update question at startup lists the changes as well.
- The theme picker and message windows now use the same custom title bar as the main window.

## 1.8.0

### Deutsch
- Cover und saubere Spielnamen aus dem Internet (api.nlib.cc), nur nach Zustimmung beim ersten Start
- „Weiterspielen“ und Sortierung nach „zuletzt gespielt“
- Fenstergröße und -position werden gemerkt
- Eigene Titelleiste im Design der Oberfläche

### English
- Covers and clean game names from the internet (api.nlib.cc), only after consent on first start
- “Continue playing” and sorting by “recently played”
- Window size and position are remembered
- Custom title bar matching the interface

## 1.7.1

### English
- Game tiles show the full name, an abbreviation and an individual colour per game
- Double-clicking the empty area of the game list no longer starts a game
